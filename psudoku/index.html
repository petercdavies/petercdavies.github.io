pSudoku

 

pSudoku is a Sudoku number puzzle game for beginners and experts alike.

Features Include

  • Daily challenge with trophies for completed months.
  • Four more difficulty levels.
  • Notes Mode to enter notes for your workings.
  • Reveal allows you to uncover a random square if you need that little bit of extra help!
  • Statistics for games played and completed and even what day is the most popular!
  • Support for dark theme.
  • Auto-saving games.
  • Works offline.

Improvement Streak

This tracks how you are improving each game by comparing the time to your previous time at the same level. Every time it's faster it adds to the Improvement Streak!

Number First

This app uses number-first input rather than cell-first. Select the number you want to use, then the cell(s) you want to place it in.

Saved Games

For each level, if the last game was still in progress, it will be automatically restarted at the point it was left. If you want a new game instead, just click new game.
